# 15 错误码总表

**单一事实源**：分段规则与细码汇总于此；各服务文档只列本域码并回链本文。错误 JSON 体见 [07-api-conventions.md](07-api-conventions.md)。

## 1. 分段

| 范围 | 含义 |
|------|------|
| 0 | 成功 |
| 10000–10999 | 通用 |
| 11000–11999 | user |
| 12000–12999 | product |
| 13000–13999 | inventory |
| 14000–14999 | cart |
| 15000–15999 | order |
| 16000–16999 | payment |
| 17000–17999 | coupon |
| 18000–18999 | search |
| 19000–19999 | notification |

## 2. 通用（10000）

| code | HTTP | 说明 |
|------|------|------|
| 10001 | 400 | 参数校验失败 |
| 10002 | 401 | 未认证 |
| 10003 | 403 | 无权限 |
| 10004 | 404 | 资源不存在 |
| 10005 | 409 | 幂等键冲突或状态冲突 |
| 10006 | 429 | 限流 |
| 10007 | 500 | 内部错误 |

## 3. user（11000）

| code | 说明 |
|------|------|
| 11001 | 账号已存在 |
| 11002 | 账号或密码错误 |
| 11003 | Refresh 无效或过期 |
| 11004 | 用户已禁用 |
| 11005 | 地址不存在 |

## 12. gRPC 映射

`InvalidArgument` / `Unauthenticated` / `PermissionDenied` / `NotFound` / `Aborted` / `ResourceExhausted` / `Internal`，并在 details 中带业务 `code`。
